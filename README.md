# Лабораторная работа № 1 — вариант 9
## Бронирование билетов на транспорт

Реализация на Python: ООП, пользовательские исключения, CRUD, JSON и XML.

### Запуск
Требуется Python 3.10 или новее. Сторонние библиотеки не нужны.

```bash
python main.py
```

При запуске приложение пытается загрузить `data/data.json`. В меню доступны просмотр, поиск по ID, создание, изменение и удаление записей, а также сохранение/загрузка JSON и XML.

### Структура
- `models.py` — 11 dataclass-моделей.
- `service.py` — CRUD, проверка внешних ключей и занятости места.
- `exceptions.py` — пользовательские исключения.
- `storage.py` — сериализация и десериализация JSON/XML.
- `main.py` — консольное меню.
- `data/` — демонстрационные данные.
- `diagram.drawio` — редактируемая UML-диаграмма.
- `docs/Отчет_ЛР1_вариант9.docx` — отчет.

### Модели
Passenger, Carrier, TransportType, Station, Route, Vehicle, Trip, Seat, Booking, Ticket, Payment.
